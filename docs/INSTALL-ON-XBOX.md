# Build, install, and transfer games to XboxWine Shelf v0.2

## Requirements

- Xbox Series X or Series S with Developer Mode activated.
- Windows PC on the same local network as the Xbox.
- Visual Studio 2022 with UWP C++ tools.
- Python 3 on the PC for the included folder uploader.
- A legally obtained, preferably DRM-free 16-bit or 32-bit Windows game.

A USB drive is not required.

## Build the app

1. Extract the XboxWine Shelf source kit.
2. Open PowerShell in the extracted directory.
3. Run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\bootstrap.ps1
```

4. Open:

```text
work\Boxedwine-uwp-uwp-compat\project\msvc\BoxedWine\BoxedWine.sln
```

5. Select `Release | x64`.
6. Set `uwp` as the startup project.
7. Build the solution.
8. Right-click `uwp` and create an app package for sideloading.
9. Select x64.
10. Keep the `.msixbundle` and `Dependencies\x64` files.

## Install through Xbox Device Portal

1. Enter Xbox Developer Mode.
2. Open **Remote Access Settings**.
3. Enable **Xbox Device Portal**.
4. Note the HTTPS address displayed by the console.
5. Open that address on the PC.
6. Accept the console's local certificate warning.
7. Open **My games & apps** and select **Add**.
8. Upload the `.msixbundle`.
9. Add every x64 dependency package generated by Visual Studio.
10. Install.
11. In Dev Home, change XboxWine Shelf's type from **App** to **Game**.
12. Launch it.

## Transfer a complete game folder

### Xbox

1. Open XboxWine Shelf.
2. Press Y.
3. Keep the **Add a Game Folder** screen open.
4. Note the displayed address, such as `192.168.1.45:24872`.

### PC

1. Run `run-uploader.bat`.
2. Enter only the IP portion, such as `192.168.1.45`.
3. Choose the complete game folder.
4. Wait for executable and key scanning.
5. Check the selected executable. Prefer one marked `x86`.
6. Select **Send folder to Xbox**.
7. Wait for both the PC and Xbox to report success.
8. Press B on Xbox to return to the library.

The game now lives in XboxWine Shelf's Xbox-local app storage. The PC does not
need to remain on when playing it later.

## Customize controls

1. Highlight the imported game.
2. Press X.
3. Select each Xbox input.
4. Cycle through detected and common keyboard/mouse inputs.
5. Press Menu to switch the right stick between mouse mode and four custom directions.
6. Press Y to save.
7. Press A on the library screen to play.

Press **View** on the library screen to cycle through other `.exe` files discovered in the imported folder.

## Storage

Large games consume the Developer Mode storage allocated to this app. Increase
its allocation from Dev Home when possible. Uninstalling, resetting, or losing
the app's local data can delete imported games.

## Common errors

### PC cannot connect

- XboxWine Shelf must be open.
- Leave the Y transfer screen open for the first test.
- PC and Xbox must be on the same network.
- Use the Xbox IP shown by the app, not the Device Portal HTTPS port.
- Allow Python through Windows Firewall on private networks.
- Confirm the manifest contains `privateNetworkClientServer`.

### Upload succeeds but no game appears

- Press B to return to the library; it rescans automatically.
- Check that the uploader received an `OK` response.
- Reopen the app if the library did not refresh.

### Wrong program launches

Run the uploader again and choose a different `.exe` from its executable list.
Updater, crash-handler, setup, and configuration executables receive a low
score, but the automatic choice can still be wrong.

### Game reports a 64-bit error

The current BoxedWine guest environment cannot run x64 Windows executables.
Use an official x86/32-bit build where available.

### Controller works in the shelf but not in the game

The current bridge maps Xbox controls to keyboard/mouse events. Open the game's
Controls page and assign keys the game actually accepts. Native guest XInput is
a later milestone.
